# Ngai Vàng Tiếng Việt

App luyện thi chữ ba vòng (Phản xạ, Xâu chuỗi, Soán ngôi) theo khung chương trình Vua Tiếng Việt. Mỗi sáng có thêm 5 chủ đề mới.

- Chơi trên web / cài lên điện thoại: https://yeuvuatiengviet-design.github.io/ngaivangtv/
- Đề nằm trong `data.json`, được cập nhật tự động mỗi ngày.
- Đề do Claude soạn, chủ kho tự duyệt. Không chép đề phát sóng của VTV.
